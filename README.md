# Simple Keyboard Event Monitor

## Overview

This project demonstrates how to capture and respond to keyboard events in Python using the `pynput` library. It is intended for educational purposes to help learners understand event-driven programming, keyboard listeners, and Python modules.

## Features

* Detects keyboard key press events
* Detects keyboard key release events
* Displays key information in real time
* Stops execution when the **Esc** key is pressed
* Simple and beginner-friendly Python implementation

## Technologies Used

* Python 3.x
* pynput

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/simple-keyboard-monitor.git
cd simple-keyboard-monitor
```

### 2. Install Dependencies

```bash
pip install pynput
```

## Usage

Run the program using:

```bash
python simple_keyboard_monitor.py
```

### Example Output

```text

Key pressed: h
Key released: h

Key pressed: i
Key released: i

Program stopped.
```
